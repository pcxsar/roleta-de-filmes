Busca automática (TMDB)

Sugere o filme certo enquanto vocês digitam, com capa, ano, sinopse e onde assistir.

  1. Crie uma conta grátis em themoviedb.org.
  2. Vá em Configurações → API e peça uma chave (uso pessoal).
  3. Copie o Token de leitura da API (o texto longo) e cole aqui embaixo.

A chave fica guardada na nuvem do app e vale pros dois aparelhos.
